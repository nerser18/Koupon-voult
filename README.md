# ארנק שוברים 🎫

אפליקציית ווב לשמירה וארגון של קופונים ושוברים: כניסה עם אימייל וסיסמה, כל משתמש רואה רק את השוברים שלו, אפשר לצלם ולצרף תמונה של השובר הפיזי, וסינון לפי קטגוריה/סטטוס/חיפוש חופשי.

**מבנה טכני:** אתר סטטי (HTML/CSS/JS ללא תלות בכלי build) + [Supabase](https://supabase.com) בתור מסד הנתונים החינמי (כולל התחברות משתמשים ואחסון תמונות) + Netlify לאירוח.

---

## שלב 1 — יצירת פרויקט ב-Supabase (חינמי)

1. היכנסו ל-[supabase.com](https://supabase.com) והירשמו / התחברו.
2. לחצו **New Project**, תנו שם (למשל `coupon-vault`), בחרו סיסמה למסד הנתונים (שמרו אותה בצד) ואזור קרוב אליכם.
3. המתינו כדקה עד שהפרויקט מוכן.
4. בתפריט הצד לחצו על **SQL Editor** → **New query**.
5. פתחו את הקובץ `schema.sql` שבתיקייה הזו, העתיקו את כל התוכן, הדביקו בעורך והריצו (**Run**).
   זה יוצר את טבלת `coupons`, את חוקי האבטחה (Row Level Security — כל משתמש רואה רק את השורות שלו) ואת ה-bucket לתמונות `coupon-images`.

### קבלת מפתחות החיבור
1. בתפריט הצד: **Project Settings** → **API**.
2. העתיקו את **Project URL** ואת **anon public key**.
3. פתחו את הקובץ `config.js` בתיקייה והדביקו:

```js
const SUPABASE_URL = "https://xxxxxxxxxxxx.supabase.co";
const SUPABASE_ANON_KEY = "המפתח-הציבורי-שהעתקתם";
```

> ה-anon key מיועד לשימוש בצד הלקוח (בדפדפן) — זה תקין ובטוח, כי כל ההרשאות בפועל נאכפות על ידי ה-RLS שהגדרתם בשלב הקודם.

### (מומלץ להתחלה) ביטול אימות אימייל בהרשמה
כברירת מחדל Supabase שולח מייל אימות בהרשמה, ולפעמים הוא נתקע ב-rate limit של השירות החינמי. כדי לדלג על זה בזמן הבדיקות:
1. **Authentication** → **Providers** → **Email**.
2. בטלו את **Confirm email**.
3. שמרו.

(אפשר להפעיל את זה בחזרה בהמשך אם תרצו זרימת אימות מלאה, או לחבר ספק SMTP משלכם ב-Authentication → Settings.)

## שלב 2 — העלאה ל-Netlify

**אפשרות א׳ — גרירה ושחרור (הכי מהיר):**
1. היכנסו ל-[app.netlify.com/drop](https://app.netlify.com/drop).
2. גררו את כל תיקיית הפרויקט (עם `config.js` המעודכן!) לתוך הדפדפן.
3. תוך שניות תקבלו כתובת אתר חיה.

**אפשרות ב׳ — דרך Git (מומלץ אם תרצו לעדכן בעתיד):**
1. העלו את התיקייה כריפו ל-GitHub.
2. ב-Netlify: **Add new site** → **Import an existing project** → חברו את הריפו.
3. השאירו את **Build command** ריק ואת **Publish directory** כ-`.` (הכל כבר מוגדר גם בקובץ `netlify.toml`).
4. **Deploy site**.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | מבנה הדף — מסך התחברות, לוח השוברים, טופס הוספה/עריכה |
| `style.css` | העיצוב |
| `app.js` | כל הלוגיקה: התחברות, שמירה/עריכה/מחיקה של שוברים, העלאת תמונות, סינון וחיפוש |
| `config.js` | פרטי החיבור ל-Supabase — **הקובץ היחיד שצריך לערוך** |
| `schema.sql` | הפקודות ליצירת הטבלה, האבטחה וה-bucket ב-Supabase |

## הרחבות אפשריות בהמשך
- תזכורות במייל כמה ימים לפני תפוגה (אפשר עם Supabase Edge Functions + cron).
- שיתוף שובר עם בן/בת זוג (טבלת `household_members`).
- סריקת ברקוד/QR מהמצלמה ישירות לשדה הקוד.
